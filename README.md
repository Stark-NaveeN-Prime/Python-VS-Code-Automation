# -Python-VS-Code-Automation
✨ Features
📁 Select a project folder
🐍 Enter a Python filename
📝 Automatically insert Python code
💻 Open the selected folder in VS Code
⚡ Automatically create the Python file
💾 Automatically save the file
▶️ Automatically run the Python application
🖥️ Simple GUI interface
🚀 Designed for quick Python development
🔒 Local Windows automation
🌐 No cloud server required for the basic workflow

🖥️ Example

Suppose you select:

D:\PythonProjects\MyApp

Enter:

calculator.py

And paste:

print("Hello from JARVISv1.0")

The automation tool can create:

D:\PythonProjects\MyApp\calculator.py

Then open the project in VS Code, save the code, and run the application.

🔐 Privacy

This application is designed around local Windows automation.

The basic workflow does not require:
❌ Cloud server
❌ User account
❌ Database
❌ Online API
❌ Uploading Python source code

Your Python code should remain on your local computer unless you intentionally use another service to upload or share it.

Always review the actual source code and dependencies before running software downloaded from the internet.

🛡️ Security

Only download the application from sources you trust.

Before running an .exe downloaded from the internet:

Scan it with Windows Security/your antivirus.
Verify the GitHub release.
Prefer the source-code version if you want to inspect how it works.
Do not run unknown executables with Administrator privileges unless necessary.
